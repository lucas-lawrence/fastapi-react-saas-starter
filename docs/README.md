# Shared Decisions

Cross-cutting decisions that apply to both frontend and backend — typically infrastructure, deployment, or integration boundaries.

## Format

| Field | Description |
|---|---|
| **Status** | Accepted / Superseded / Deprecated |
| **Context** | The problem or situation that required a decision |
| **Decision** | What we chose |
| **Consequences** | Trade-offs, follow-up work, or things to watch |
